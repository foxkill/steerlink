SteerLink lets Grok Bot hand coding tasks to Claude Code — or any other ACP coding agent. Each edit and command comes back to you as a question, with the diff, before anything happens.

Your bot plans. A coding agent builds. You decide.

The bridge connects two open protocols — MCP on the bot's side, ACP on the agent's side — the same way the Zed editor runs external agents.

Approve every change

Edits and commands arrive as permission requests with the diff and the options Allow once, Always allow, Deny. Nothing is written without an answer.

Your key, your bill

Each user enters their own Anthropic API key in the plugin settings. The bridge passes it to the agent process and nowhere else — never into logs or tool output.

Any ACP agent

Claude Code is built in. Add Codex or any other ACP agent with three lines of config, modelled on Zed's agent_servers.

Long tasks, no blocking

Start a turn with wait: false and long-poll for progress. The bot stays responsive while the agent works.

Answers the bot can use

Every call returns compact JSON: status, response text, tool calls with diffs, pending permissions and a hint for the next step.

Tested end to end

Over 130 automated tests, a validator for the plugin format, and a package test that installs the published bundle and runs it through npx.

How it works

The bridge is an MCP server. It starts the coding agent through its official ACP adapter, unmodified, and translates in both directions.

MCP hostGrok Bot

Understands your request, calls the bridge's tools and shows you every permission request.

⇄MCP · stdio
This pluginSteerLink

Sessions, permission queue, event buffer, secret-free auth status.

⇄ACP · stdio
Coding agentClaude Code

Reads and edits your project and runs commands — only after you approve. Or Codex, or another ACP agent.

What the bot sees

Real responses of the bridge, recorded with Claude Code (shortened). Your bot turns these into the conversation above.

A change waits for approval

send_prompt returns as soon as the agent needs a decision.

{
  "status": "awaiting_permission",
  "pending_permissions": [{
    "permission_id": "perm-1",
    "title": "Write hello.txt",
    "kind": "edit",
    "diffs": [{ "path": "hello.txt", "old_text": null, "new_text": "hi" }],
    "options": [
      { "option_id": "allow", "name": "Allow", "kind": "allow_once" },
      { "option_id": "reject", "name": "Reject", "kind": "reject_once" }
    ]
  }],
  "hint": "Agent is waiting for approval. Call respond_permission …"
}

The turn is done

get_session_updates after the approval: what changed, and how it ended.

{
  "status": "idle",
  "last_turn": {
    "stop_reason": "end_turn",
    "response_text": "Created hello.txt with the content hi.",
    "tool_calls": [{
      "title": "Write hello.txt",
      "kind": "edit",
      "status": "completed",
      "diffs": [{ "old_lines": 0, "new_lines": 1 }]
    }]
  }
}

Sign-in status, without secrets

auth_status tells the bot whether a key is there — never the key itself.

{
  "auth_mode": "api_key",
  "credentials": { "anthropic_api_key_set": true },
  "agent_reported": { "kind": "api_key", "label": "Anthropic API key" },
  "problem": null
}

Forgot the key? A clear hint.

An unset plugin variable is caught before the agent starts.

{
  "auth_mode": "api_key",
  "credentials": { "anthropic_api_key_set": false },
  "problem": "… ANTHROPIC_API_KEY is the unexpanded placeholder
    ${ANTHROPIC_API_KEY}. Enter your own Anthropic API key
    in the plugin settings."
}

Set up in three steps

Install the plugin, add your key, ask your bot. The server runs where your bot runs — for Grok Bot, on its own computer.

Install the plugin

From the plugin marketplace of your host, or as a plain MCP server:

{
  "mcpServers": {
    "steerlink": {
      "command": "npx",
      "args": ["-y", "steerlink@0.1.3"]
    }
  }
}

Add your API key

Set the plugin variable ANTHROPIC_API_KEY to your own key from the Claude Console. Never paste it into the chat. 

ANTHROPIC_API_KEY = sk-ant-…

Ask your bot

Describe the task and the project. The bot starts a session and asks you before every change. 

"Let Claude Code add input
validation to ~/projects/api
and run the tests."

Twelve tools, one job

Everything a bot needs to run a coding agent safely.

Tool What it does
start_session Start an agent session in a project directory, optionally with an agent and a mode
send_prompt Send a task; returns when the turn ends, a permission is needed, or the timeout passes
get_session_updates New events since the last call, with long-polling
list_pending_permissions Open permission requests with diff and options
respond_permission Allow or deny, once or always
set_mode · cancel Switch the session mode, stop the running turn
close_session · list_sessions Manage sessions
list_agents Configured agents and their sign-in methods
auth_status · authenticate Sign-in status without secrets; agent sign-in methods

Questions

Who pays for Claude?

You do, directly to Anthropic, through your own API key. The bridge does not resell or route Claude usage, and it never sees your Claude credentials.

Can the agent change files without asking?

Not in the default mode. Every edit and command becomes a permission request. The plugin's instructions tell the bot to ask you and never to switch to a mode that skips approvals on its own.

Where does the agent run?

On the machine where your host runs MCP servers. For Grok Bot that is Grok Bot's computer, so project paths refer to that machine.

Why does the first start take a while?

The first start downloads the package and its dependencies, about 300 MB — most of it the native Claude Code binary that ships with Anthropic's Agent SDK. Later starts are fast.

Which agents work besides Claude Code?

Any agent that speaks ACP, for example Codex through codex-acp. Each agent's own terms apply.

Is it free?

Yes. SteerLink is open source under the MIT license. If it saves you time, you can support its development via PayPal. Donations are voluntary and do not buy access or Claude usage.
